# Nuhash Jobayed — Portfolio (v2)

Next.js 15 · React 19 · React Three Fiber 9 · three.js · GLSL · GSAP ScrollTrigger · Lenis

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Pages

| Route | What it is |
|---|---|
| `/` | The homepage journey (below) |
| `/work` | All work — list with slanted hover previews |
| `/work/[slug]` | Case study (stub — next page to design) |
| `/about` | Story, photo, Career Ledger, skills |
| `/blog`, `/blog/[slug]` | Notes from the workbench (3 planned posts, marked as drafts and kept out of search) |
| `/playground` | Shader experiments grid |

Every page shares the 3D logo, the minimal menu (top right), the cursor, sound toggle and the footer.

## The homepage

| # | Section | File | What happens |
|---|---|---|---|
| 00 | Loader | `components/chrome/Loader.tsx`, `Grain.tsx` | Fine film grain, signature writes itself, slot counter shows **real** progress, then one solid shutter rolls up. |
| 01 | Hero | `components/journey/*` | Red/orange northern lights, water-brush cursor, a clear cut diamond refracting the light. Showreel tile (click → full-screen video). Name slides apart, the diamond swells and breaks (sound: impact). |
| 02 | Intro | `Journey.tsx` | The light burns away bottom → top (no particles). Photo + story, words un-blur. |
| 03 | Into the dark | `JourneyScene.tsx` | Blood-red river. The cursor becomes a glowing orb that lights the river. Shards dissolve as the camera glide starts. Three lines appear above the door; each keeps its red key word, which drops into a phrase at the bottom. Door blooms only after the last line. |
| 04 | Selected Work | `components/work/*` | 3D spiral staircase of 7 projects, red cursor on white, **View all work** button. |
| 05 | Skills | `components/Skills.tsx` | Statement + accordion. |
| 06 | Words | `components/Testimonials.tsx` | Dot-matrix world map revealed outward from Dhaka, arcs to client countries, reviews fade in near their country. |
| 07 | Contact | `components/Contact.tsx` | A ring of light opens into a circle that reveals the main shader background. White text. |
| 08 | Footer | `components/footer/*` | Main red/orange light behind everything, one whole diamond floating in it. Hovering the stone turns the area around the cursor into Raster Lines. |

Cursor effects everywhere:
- Elements with `data-liquid` (headings, photos, video tile) ripple like water under a moving cursor.
- Links and buttons with the class `disperse` split into red/cyan channels on hover.
- The cursor turns red over light backgrounds.

All scroll timings for 01–03 live in **`lib/timeline.ts`**. All copy lives in **`lib/content.ts`**.

## Replace the placeholders

## Sound

Off until the visitor turns it on. Then: ambient pad (or your track), an impact when the stone breaks, a burning whoosh for the dissolve, a bell for each river line, a rising swell toward the door, and soft ticks and whooshes on hovers, the menu and the video.

## Performance

- Each canvas only renders while on screen. The journey stops and hides once you scroll past it.
- Phones and weak machines get fewer shards, a smaller fluid sim, lower resolution and a shorter journey.
- No WebGL2 or `prefers-reduced-motion` → static gradients, a flat project grid, all text still readable.
